# Contributing

Thank you for your interest in improving this project.

- Keep pull requests focused and describe the integrity or operational use case.
- Add tests for behavioural changes and regression fixes.
- Update documentation when commands, manifest fields, or limitations change.
- Run `python -m unittest discover -s tests -v` before opening a pull request.
- Include test output and compatibility impact in your pull request description.

Avoid adding runtime dependencies unless there is a clear operational benefit.
